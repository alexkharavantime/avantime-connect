# Безопасность
- Приватный ключ WG клиента НЕ покидает устройство (на backend — только публичный).
- Секреты клиента — Windows Credential Manager / DPAPI.
- Пароль пользователя нигде не хранится в системе (вводит сам, сохраняет через mstsc).
- Одноразовые токены приглашений: отзываемые, с истечением.
- Backend + MongoDB — закрытый контур, наружу не торчат.
