# Безопасность
- Windows-клиент создаёт приватный ключ на устройстве (на backend — только публичный). При ручной выдаче для Mac ключ создаётся в браузере администратора, остаётся в памяти вкладки и скачанном `.conf`, который передаётся владельцу Mac защищённым способом. Сервер приватный ключ не получает и не хранит; повторный экспорт после закрытия формы невозможен.
- Секреты клиента — Windows Credential Manager / DPAPI.
- Пароль пользователя нигде не хранится в системе (вводит сам, сохраняет через mstsc).
- Токен приглашения закрепляется за одним устройством и имеет срок для новой регистрации. Отдельный API отзыва приглашений пока не реализован; устройство можно отозвать в pending/active.
- Завершённый enroll восстанавливается по той же тройке token/key/device в течение ENROLL_RECOVERY_TTL (86400 секунд). Снимок и токен не логировать; токен исключён из списка устройств.
- Административный Bearer-токен обязателен для SSH-режима; проверяется также в disabled, если задан. Пользовательских ролей/TLS reverse proxy/rate limit/полного аудита пока нет.
- Только подтверждённое удаление даёт revoked; managed.json и IP-резерв сохраняются. Чужие peers не изменяются. Строгая проверка SSH host key обязательна.
- Backend + MongoDB — закрытый контур, наружу не торчат.
